## 1. 基础

### 1.1 常用滤镜效果

人物阴影 `filter: drop-shadow()`、磨砂玻璃 `backdrop-filter:` 。



### 1.2 var 和 let 的区别

- 全局污染
- 块级作用域
- TDZ暂时性死区
- 变量重复声明
- const 定义后不能更改



### 1.3 剪切板对象无法获取

只有一下三种情况可以获取 clipboard 对象：localhost、127.0.0.1、https。否则使用传统 copy 命令。



### 1.4 reflect的本质

直接调用对象的基本操作(内部方法)。



### 1.5 稀疏数组

for 循环 --> if(i in array)，通过这个步骤去判断。



### 1.6 动态执行JS

eval、setTimeout、script、new Function。



### 1.7 CSS原子化

用类名来代表样式，**tailwind**、windi、uno。



### 1.8 never类型的妙用

尽早在**编译时**发现问题。



### 1.9 水印防篡改

MutationObserver。
